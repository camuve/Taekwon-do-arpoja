Taekwon-Do-arpojan Hangul- ja puhepäivitys

index.html sisältää tekniikkadatan sekä _hangulByName-kartan, jotta se toimii GitHub Pagesissa ja paikallisesti ilman fetch-riippuvuutta.
tekniikat-hangul.json on ylläpidon muokattava JSON-kopio samasta datasta.

Puhevalinnat: Robotti (nykyinen romanisoitu nimi) ja Korea (Hangul, ko-KR-puheääni jos laitteessa saatavilla).
Huom: selaimen Korean ääni riippuu iPhonen/selaimen käytettävissä olevista puheäänistä.
